# 虚构对话回放输入

cases.json 为人工设计的开发样例，完全虚构，不是原视频转写，不是保留测试集。时间为相对会话的毫秒，不能用于声称产品实测延迟。

每例 events 是有序稳定转写；checkpoints 是算法应接受评估的位置。每个检查点只能看该时间及以前的事件，禁止将未来澄清提前喂给模型。sources 中的资料视为会前已提供。

gold 仅给评估器和人工审核，不能放入模型输入。allowed_actions 是策略级期望，不要求逐字生成。required_source_ids 用于核查提醒/回答的证据。禁止断言是语义条件，不能只做关键词匹配。

当前没有执行器和模型实验结果。JSON 格式、引用与时间顺序检查只证明样例内部一致，不能证明算法有效。
