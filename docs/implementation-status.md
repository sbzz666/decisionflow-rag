# v0.2 实现与验证

## 已实现

- FastAPI + WebSocket 后端，React + TypeScript 前端，SQLite 本地会话持久化。
- 资料分块、中文双字词/英文词项 BM25 检索、上下文预算、来源 ID 与字符偏移引用。
- 两个固定分析角色并行执行，候选证据审核；独立问答路径。编排使用 asyncio，不使用 LangGraph。
- 参与模式、提醒去重、预设付款澄清、引用删除清理、执行轨迹。
- 浏览器语音识别后编辑发送及可选朗读；不是独立连续 ASR。
- 模型接口预留，但未配置真实密钥。离线模式显式标记检索或规则演示。

## 验证

本机 14 项后端测试通过，模型请求使用 Mock；TypeScript 检查与 Vite 构建通过。覆盖 RAG 分块、偏移、预算、无命中、会话隔离、引用持久化、伪造引用和删除清理，以及已有会话工作流。v0.1 页面已验证演示、追问和澄清，截图保留为历史展示。

GitHub Actions 已定义测试和构建任务，但尚未在远端运行。不报告实际大模型准确率或生产性能。Starlette TestClient 当前有 httpx 弃用警告，不影响已执行的测试。

## 未实现与边界

无向量 Embedding、神经重排序、文件上传解析、OCR、跨会话自动记忆或多租户权限。
无完整跨 Agent 冲突仲裁、动态任务规划、模型 token 流式输出或中断旧分析。
没有个人微信、邮件发送或独立实时语音识别。当前服务仅限本机个人使用。

详见 [RAG 设计](rag.md)。其余架构、算法和评估文档是研究方案，不是交付清单。
